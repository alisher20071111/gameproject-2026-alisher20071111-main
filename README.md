Игрок управляет персонажем в замкнутой арене и должен выживать против бесконечных волн врагов.В процессе игры появляются быстрые и тяжелые противники, а после убийства врагов могут выпадать аптечки для восстановления здоровья. С каждой новой волной количество врагов увеличивается, повышая сложность игры.
